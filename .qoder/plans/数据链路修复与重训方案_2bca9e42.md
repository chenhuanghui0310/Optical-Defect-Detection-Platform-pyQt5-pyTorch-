# 数据链路修复与重训方案

## 背景诊断（已证实的问题）
1. **核心bug**：`auto_dataset_generator.py` 只对瑕疵图施加随机增强（亮度±8%/对比度/噪声/模糊/JPEG），而 `split_final_dataset.py` 用 absdiff(瑕疵图,理想图) 以 4~12 灰度级低阈值生成标签 → 约一半样本标签框被污染到条纹带上（实测 diff mean 高达 13~49，与缺陷强度无关）。
2. 61.8% 的凸起/凹陷高度 <0.1μm，其中大量样本走"解析半径框"回退，框贴在无可见异常区域。
3. 框口径不一致（diff 框 vs 物理半径×shrink 框），`max_boxes_per_image=12` 截断造成同缺陷时标时不标。
4. split94 训练用了有害增强（scale=0.5、erasing=0.4、randaugment）。
5. 实例失衡：dust 7619 / hair 6227 框 vs bump 1947 / dent 2133 框。

## 一、生成端修复（auto_dataset_generator.py）
1. **同参数增强（最关键修复）**：增强参数（亮度、对比度、模糊σ、噪声种子）一次性采样后，对理想图与瑕疵图施加**完全相同**的变换与同一噪声场，使差分中全局分量与噪声精确抵消；删除 JPEG 压缩伪影步骤（内容相关、无法两图对齐）。
2. **弱形变样本加密**：凸起/凹陷样本中约 50% 走弱形变聚焦分布——高度/深度 h∈[0.014, 0.030]μm（中心 0.02）、半径 r∈[2.7, 3.2]mm（中心 3.0），劈尖与牛顿环均覆盖；其余样本分层覆盖原全范围（含可见性下限样本）。
3. **bump_count 上限 10→6**，消除标签截断矛盾。
4. **纯仿真**：不引入任何 real 数据；类别配比向凸起/凹陷倾斜（目标 4000 张：凸起 1000、凹陷 1000、划痕 600、灰尘 700、头发 700）。
5. 增强参数与随机种子写入 `_参数.json` 的 `aug_params` 字段，便于审计与复现。
6. 输出到新目录 `dataset/images/Final_Dataset_v2`，不覆盖旧数据。

## 二、标注端修复（split_final_dataset.py）
1. **差分偏置校正**：absdiff 后减去全局中位数（消除残余线性偏置），阈值下限 4→12。
2. **统一框口径**：解析位置仅作为 diff 搜索的 ROI 提示；最终框一律 = diff 轮廓 + 固定 padding（约15%）；已知位置无可见信号 → 丢弃该样本（弱形变样本因标签链路已干净、局部 diff 信号仍可达 ~70 灰度级，多数可保留）。
3. 输出到 `dataset/final_split_yolo_v2`（`--clean`，固定 seed，val/test 各 10%）；保留现有 rebalance 与小目标 manifest 逻辑。

## 三、回归集重建（覆盖双实验多波长）
构建固定回归集 `dataset/regression/physics_v2`：{劈尖, 牛顿环} × {红 632nm, 绿 532nm, 蓝 470nm} × {弱凸起(h≈0.02,r≈3), 弱凹陷(h≈0.02,r≈3), 强缺陷各1}，约 12~16 张固定参数图，用固定 seed 生成、永不入训练。同步更新 `DEVELOPMENT_MEMORY.md` 的回归集表格与决策序列。

## 四、重训（train_final_split.py）
- 启用 `--small-target-preset`（imgsz=1280）+ 默认 `local_defect_preset`（scale=0.15、translate=0.02、关闭 erasing/randaugment/mosaic）。
- run 名 `yolo11s_final_v2_1280`，epochs 120，batch 4~6。
- 不替换 OpticalLab 部署权重，直到候选在回归集与 held-out 上超过 baseline。

## 五、验收与记录
1. **训练前**：`audit_dataset_labels.py` 生成 contact sheet，人工抽查凸起/凹陷框贴合度；抽样 20 张验证 diff 干净（mean < 3）。
2. **训练后**：与 split94 对比逐类 P / R / mAP50 / mAP50-95（重点 bump/dent），统计置信度分布；跑 `validate_small_targets.py` 与弱形变 manifest 评估；`evaluate_regression.py` 出回归报告。
3. 更新 `DEVELOPMENT_MEMORY.md`（变更原因、文件、验证结果、下一决策点）。

## 测试计划
- 生成端：抽样验证"瑕疵图-理想图"差分 max 由缺陷决定、mean < 3（无全局污染）。
- 标注端：contact sheet 检查框与可见条纹畸变对齐、无条纹带框。
- 训练后：同域逐类指标对比 + 弱形变子集召回率。

## 假设与风险
- GPU 可用（device 0）；生成 4000 张约数小时、1280 训练约 8~12 小时，可接受。
- h≈0.02μm 样本条纹弯曲 <1/15 周期，即使标签干净，单样本判别难度仍高——预期该项表现为"框准但置信度中等"，属物理极限，不代表修复失败。
- 旧数据集与 split94 全部保留用于对比，不删除不覆盖。
