# 新旧两版关键对比（smallscale_v2）

## 1. 数据集版本对比

| 项目 | 旧版 Final_Dataset | 新版 Final_Dataset_smallscale_v2 |
|---|---:|---:|
| 总样本数 | 1000 | 1000 |
| 类别分布 | 表面划痕/小突起/小凹陷/灰尘污染 = 250/250/250/250 | 表面划痕/小凸起/小凹陷/灰尘污染 = 250/250/250/250 |
| 命名统一 | 使用“小突起”“突起划痕” | 统一为“小凸起”“凸起划痕” |
| 小尺寸增强 | 低 | 明显增强 |

### 小尺寸统计（参数级）

- 旧版：
  - 小突起小高度(<=0.08um)：12
  - 小凹陷小高度(<=0.08um)：15
  - 凸起划痕样本：几乎无
- 新版：
  - 凸起划痕样本：136
  - 小凸起小高度(<=0.08um)：109
  - 小凹陷小高度(<=0.08um)：111

## 2. 切分策略对比

- Train: 800
- Val: 100

## 5. 最终结论

1. 新版已完成目标性改造：小尺寸样本增强、命名统一（小凸起/凸起划痕）、8:1:1 切分。
2. 从当前这组实验结果看，smallscale_v2 在检测指标上显著低于旧版，未带来精度提升。
3. 若以比赛主成绩为优先，建议继续以旧版模型作为主提交方案（旧版最终 mAP50-95 = 0.995）。
4. 新版更适合作为“鲁棒性与工程探索”的补充实验：证明你尝试了小尺寸增强与命名规范化，但当前参数分布会拉低整体检测指标。
5. 下一步建议：在保留小尺寸样本的前提下，降低其占比或分阶段训练（先旧版高精度收敛，再用小尺寸集做短轮次微调），再复测是否能兼顾总体精度与小尺度表现。
